Help & Documentation

Overview

The RMA Configuration Migration Wizard automates the process of transferring configuration from a failed Cradlepoint router to its replacement device using the NCM API v2. It ensures device compatibility, backs up configurations, and verifies successful migration.

Workflow Steps

1
API Keys

Enter your NCM v2 API credentials (X-CP-API-ID, X-CP-API-KEY, X-ECM-API-ID, X-ECM-API-KEY). These are validated against the NCM API before proceeding.

2
Source Device

Select the group containing the failed router, then select the specific device. The wizard displays device details for confirmation.

3
Source Configuration

The wizard retrieves both group-level and device-level configurations from the NCM Configuration Manager endpoint. Review both configs before continuing.

4
Destination Device

Select the replacement router. The wizard validates that it is the same model and running equal or newer firmware. It is recommended to place the destination in a staging group with matching firmware first.

5
Destination Config (Resolve)

Any masked fields (shown as "*") in the source config represent encrypted values that cannot be read. For each, choose: set to blank, use destination serial number, enter a custom value, or exclude the field.

6
Apply Migration

Review the migration summary and confirm. The wizard moves the destination device into the source router's group (inheriting group config) and patches the resolved device-level configuration.

7
Verification

After a brief delay the wizard checks that configuration has synced to the device. It reports sync status, any remaining masked fields requiring manual attention, and whether sync is suspended.

Important Notes

  • Fields with a value of "*" (passwords, PSKs, VPN credentials, SNMP community strings) cannot be migrated and must be manually reconfigured.
  • The destination device must be the same model as the source and running the same firmware version.
  • It is recommended to place the destination device in a staging group with matching firmware before starting the migration.
  • Group-level configuration is inherited automatically when the device is moved to the source group.
  • If the configuration sync shows as "pending", wait a few minutes and use the Re-verify button to check again.
  • This tool runs locally and is never deployed to a router. API keys are held in memory only during the session.

API Key Requirements

Only NCM API v2 keys are required. You need both X-CP and X-ECM credential pairs. These can be generated from the NCM accounts page under API Keys. No API v3 Bearer Token is needed for RMA migration.
