How to use NCOS Downloader

1. Credentials

Enter your four NCM v2 API keys — X_CP_API_ID, X_CP_API_KEY, X_ECM_API_ID, X_ECM_API_KEY — in Settings (gear icon). Save them as a named profile to switch between accounts. The app also picks them up from the environment if they are already set there.

2. Build the catalog

NCM's /firmwares/ endpoint has no "list by model" filter, so the app pulls the whole catalog once (about 10 seconds) and joins it against /products/ to resolve model names. The result is cached on disk, so later visits load instantly. Use Refresh Catalog after a new NCOS release.

3. Find your image

  • Filter by Model, Version, or free-text Search.
  • Click a stat card to filter — Latest per Model is the quickest way to find current firmware.
  • Click any column header to sort. Click a Model or Version cell to search for it.
  • Deprecated images are hidden by default; Expired ones are still downloadable but past their NCM expiry date.

Why does each version appear twice?

Because NCM usually publishes two images per build: a standard one and a multiimage one. They share the same model, version, and build timestamp, and differ only by the multiimage tag in the firmware URL — and by their SHA-1. The Image column shows which is which, and Hide multiimage in the filter bar collapses the list to one row per build.

The API gives no field describing what the difference means, so if you are unsure which your deployment expects, check with the NCM release notes rather than guessing. Roughly 2,000 of the 17,700 images in a full catalog are multiimage builds.

4. Download

Tick rows and use Download Selected, or use the per-row button. Transfers run in the background on the Downloads tab, several at a time, and each file's SHA-1 is checked against the hash NCM publishes. A failed check deletes the partial file rather than leaving a corrupt image on disk. Files land in the download folder set in Settings and can be saved to your browser or deleted from the Downloads tab.

Notes

  • Images are named MODEL-VERSION.bin. NCM often publishes several distinct builds of the same model and version, so where that happens the build date and a short hash are added — IBR600C-7.26.100-20260916-d53a04.bin — to keep the builds apart. A name already on disk is skipped, so re-downloading is safe.
  • The .bin files come from Cradlepoint's CDN, referenced by each firmware record.
  • This app serves on localhost with no authentication. Don't expose the port on a shared network — anyone who reaches it could read the credentials in Settings.
