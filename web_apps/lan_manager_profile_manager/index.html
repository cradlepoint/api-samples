Settings

Keys are stored in plaintext in profiles.json beside this app, and this server has no authentication. Keep it on localhost.

Routers processed in parallel. Each router takes 3–6 API calls; NCM allows roughly 500 calls a minute per account. Remembered in this browser.

User guide

What this manages

Remote Connect LAN Manager profiles (SSH, HTTP, HTTPS, RDP, VNC, Serial) stored per router in NCM, and the per-router LAN Manager on/off switch. Both live in the NCM API v3, so an NCM_API_TOKEN is required.

How pushes work (Create and Copy)

  • LAN Manager is enabled automatically on every router a profile is pushed to.
  • Profiles are matched by name, ignoring case. If a router already has one, it is updated in place. Any extra copies with the same name are deleted, so a router never ends up with duplicates.
  • If the type differs (e.g. SSH → HTTPS), the new profile is created first and the old one deleted after.
  • A router that already has an identical profile is left alone and reported as unchanged.
  • Pushes are safe to repeat. Add routers to a group, push to the group again, and only the new routers change.
  • Each router is re-read live at run time and re-read again after writing, to verify.

Finding wrong profiles (Profile name)

In the destination, choose Profile name and search a name (case-insensitive). Every router with a profile of that name appears, grouped into variants. A variant is a set of profiles that are identical in type, exact name, port, address, username and resolution. The largest variant is usually the correct one.

  1. Choose Copy profile, then in Profile name mode click Use as source on the correct variant.
  2. Tick the wrong variants (or individual routers inside them) as the destination.
  3. Preview, then Run. The wrong ones are overwritten with the correct one.

Deleting

  • Routers / Groups: pick routers, then tick which profile names to delete from them (or all).
  • Profile name: tick whole variants or individual routers. Only those exact profiles are deleted.
  • Deleting profiles never disables LAN Manager. Use Disable LAN Manager for that.

Orphaned profiles

NCM keeps profiles after a router is unregistered or deleted. This view lists profiles whose router ID is not in your v2 router list. Note that a router moved into an account these API keys cannot see would also show here, so spot-check before deleting.

Logs

Every run writes logs/lan_manager_<action>_<timestamp>.log with each router, every create/update/delete, and the previous values of anything replaced or deleted, so a change can be undone by hand.
